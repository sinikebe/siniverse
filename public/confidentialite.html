Confidentialité

Cette page explique le fonctionnement de Finapp et de Garapp, les deux applications de Siniverse. La sauvegarde Google Drive est facultative : les applications restent utilisables sans compte Google.

Mise à jour le 12 novembre 2026.

Les données dans les applications

Vos scénarios financiers dans Finapp, vos informations de véhicules et vos documents dans Garapp sont enregistrés sur votre appareil. Vous pouvez les exporter depuis chaque application. Le site Siniverse ne reçoit pas ces données lorsque vous utilisez uniquement le stockage local.

Sauvegarde Google Drive

Si vous choisissez de connecter Drive, l'application demande votre autorisation pour le droit Google drive.file. Elle utilise cet accès pour créer, retrouver et lire ses sauvegardes dans votre propre Google Drive. Elle lit aussi le nom et l'adresse e-mail associés au compte Drive pour afficher le compte connecté. Finapp et Garapp ont chacun leur propre autorisation Google.

Les sauvegardes sont transférées directement entre votre navigateur et l'API Google Drive, puis conservées dans votre Drive. Le serveur Siniverse ne stocke pas vos sauvegardes, vos documents, vos données financières ou vos informations de véhicule. Il ne reçoit pas votre mot de passe Google.

Rester connecté

Pour éviter de redemander la connexion à chaque ouverture, le service api.siniverse.cc conserve chez Cloudflare un identifiant de session sous forme d'empreinte, les dates d'expiration et les jetons Google nécessaires à la connexion. Les jetons de renouvellement et les éventuels jetons d'accès temporaires conservés côté serveur sont chiffrés. Le navigateur reçoit un cookie de session protégé (Secure, HttpOnly, SameSite=Lax) valable jusqu'à 30 jours après la dernière utilisation de la session.

Un jeton d'accès court est aussi utilisé en mémoire par l'application pendant les échanges directs avec Drive. Il n'est pas enregistré durablement dans le stockage du navigateur. Les autorisations de Finapp et Garapp restent séparées.

Les sessions expirées sont supprimées de la base active. Cloudflare conserve toutefois un historique technique de sa base D1 pouvant permettre une restauration pendant 7 jours sur l'offre gratuite (30 jours sur l'offre payante) ; les jetons présents dans cet historique restent chiffrés. En savoir plus sur cet historique.

Gérer ou supprimer l'accès

Le bouton « Se déconnecter » de chaque application met fin à sa session sur cet appareil. Il ne supprime pas les sauvegardes déjà présentes sur votre Drive. Vous pouvez gérer ces fichiers dans Google Drive et retirer à tout moment l'autorisation de l'application depuis les connexions tierces de votre compte Google. Une nouvelle autorisation sera nécessaire si la session expire ou si Google retire l'accès.

Les données locales restent sur votre appareil tant que vous ne les effacez pas dans l'application ou dans les paramètres du navigateur.

Services et contact

Cloudflare héberge les sites et le service de connexion ; Google fournit la sauvegarde Drive. Leurs traitements techniques sont également décrits dans leurs règles de confidentialité et règles de confidentialité respectives. Siniverse n'intègre actuellement aucune publicité ni traceur publicitaire.

Pour contacter le projet, consultez son dépôt GitHub ou l'adresse d'assistance indiquée sur l'écran d'autorisation Google. Ne publiez pas de données personnelles ou de sauvegardes dans un espace public.
